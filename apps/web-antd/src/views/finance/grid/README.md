# 网格策略试用页

入口：登录后进入“资产管理 → 网格策略”，地址为 `/dashboard/grid`。

当前版本支持新建、编辑、查看和删除策略，展示逐档买卖价、交易股数、理论盈利，以及压力测试下的投入和浮亏。首次进入可点击“载入截图示例”，核对云铝策略的 7 档、700 股、15,529.50 元投入和 2,740.50 元浮亏。示例需用户主动保存，不会自动写入。

策略保存在当前浏览器的 `localStorage`，键按租户与登录用户隔离；清除站点数据后无法恢复，也不会跨设备同步。此功能不修改家庭资产账本中的账户或余额。

试用计算口径：以触发价格为基准，按固定价差 `触发价格 × 网格大小` 递减。等额买入时每档以网格金额为预算；逐格加码时，每种网格的第 `i` 档预算为 `网格金额 × (1 + i × 加码比例)`，序号从 0 开始。买入股数按预算向下取整到 100 股。

中网和大网开启后，默认间距分别为 15% 和 30%，可分别修改；小、中、大网独立从触发价格开始生成档位，价格重合时分别买入并累计投入与股数。每种网格的卖出价为对应买入价加本类型的固定价差。

压力测试假设价格单向下跌、各档买入后不卖出；盈利额是未扣费毛收益。压力终点与网格间距不整除时，浮亏按实际终点价格计算。所有网格合计最多 200 档。手续费、滑点及标的报价单位尚未定义；正式接入时需要确认，并将策略迁移到服务端持久化。
